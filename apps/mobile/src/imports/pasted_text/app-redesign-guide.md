Redesign the existing mobile UI in this project to make it more user-friendly, readable, and comfortable for touch interaction.

The main problem with the current UI is that many elements feel too small and compressed, especially input fields, buttons, typography, and spacing.

General Rules

* This is a Persian-language mobile application.
* Keep the entire interface RTL (Right-to-Left).
* Keep the existing Dark Theme.
* Preserve the existing color palette and visual identity.
* Do not change the overall navigation structure.
* Do not change the existing texts, service names, or functionality.
* Do not add unnecessary new features.
* Focus only on improving UI/UX, sizing, spacing, typography, readability, and touch usability.
* The design should feel comfortable for one-handed mobile use.

1. Input Fields and Forms

Make all existing input fields larger and more comfortable to use with a finger.

Recommended specifications:

* Standard input height: 64–72px
* Large input / textarea height: 90–110px minimum
* Horizontal input padding: 18–24px
* Vertical input padding: 14–18px
* Border radius: approximately 16–20px
* Border width: approximately 1.5–2px
* Input text size: 17–19px
* Placeholder text size: 16–18px

For simple fields, place the field name directly inside the input as a placeholder instead of using a separate label above it.

Example:

Instead of:

Phone Number

[              ]

Use:

[ Phone Number                         ]

The placeholder should be clearly readable but use a medium/light gray color.

When the user enters a value, the entered text should have higher contrast and be visually more prominent than the placeholder.

If a separate label is necessary for clarity, keep it, but use consistent spacing between the label and the input.

2. Form Titles and Labels

Avoid unnecessary visual clutter.

For simple inputs, prefer an internal placeholder.

For example:

* "Mobile Number"
* "Amount"
* "Card Number"
* "Description"
* "Source Card"
* "Destination Card"

These should appear inside the relevant field in a subtle gray color when the field is empty.

Do not make labels unnecessarily small.

3. Buttons

Make all primary buttons larger and easier to tap.

Recommended specifications:

* Primary button height: 56–64px
* Secondary button height: 52–56px minimum
* Border radius: approximately 18–24px
* Button text size: 18–20px
* Button text weight: Medium or Semibold
* Horizontal padding: at least 24px

Buttons such as:

* "Confirm"
* "Continue"
* "Next Step"
* "Inquiry"
* "Submit"

should follow one consistent button size system throughout the application.

The buttons should have enough height and spacing to be easily tapped with a finger.

4. Spacing and Layout

The current UI feels too compressed.

Increase the vertical spacing between elements while keeping the layout clean and efficient.

Recommended spacing:

* Label to input: 8–12px
* Between two input fields: 16–20px
* Between separate form sections: 24–32px
* Between the last input and the primary button: approximately 24px
* Page horizontal padding: approximately 24–32px

Avoid placing elements too close together.

Give important components enough breathing room.

5. Typography

The current typography is too small in several areas.

Increase font sizes to improve readability on mobile.

Recommended sizes:

* Main page title: 24–28px, Bold/Semibold
* Section title: 18–20px, Semibold
* Main body text: 16–18px
* Input text: 17–19px
* Placeholder text: 16–18px
* Button text: 18–20px
* Secondary/helper text: 14–16px minimum

Do not use very small text for important information.

Maintain a clear typography hierarchy between page titles, section titles, body text, labels, placeholders, and buttons.

6. Touch Targets

Optimize every interactive element for finger interaction.

No important interactive control should be too small.

This includes:

* Buttons
* Inputs
* Dropdowns
* Select controls
* Icon buttons
* Copy buttons
* Navigation controls
* Cards that can be selected

Recommended minimum touch target: 44–48px.

The actual icon can remain smaller, but its clickable/touchable area should be large enough for comfortable interaction.

Maintain enough spacing between adjacent interactive elements so users do not accidentally tap the wrong option.

7. Select and Dropdown Fields

Make all Select and Dropdown components consistent with the input fields.

Recommended height: 64–72px.

Selected text should be at least 17–18px.

Dropdown arrows and icons should have an adequate touch area.

All similar form components should use the same visual system.

8. Cards and Selectable Options

Increase the size of selectable cards and option buttons where necessary.

Cards should have enough height for their text and icons.

Selectable options should have sufficient spacing between them to make finger interaction easy.

Do not make cards unnecessarily compact just to fit more content on the screen.

9. Responsive and Consistent Design

Apply these improvements systematically across the application.

If multiple pages use the same type of Input, Button, Select, Card, or other component, update the shared component/design system so all instances remain consistent.

Do not create random sizes for similar components.

Use a consistent spacing scale, typography scale, button height, input height, border radius, and touch-target system.

10. Priority Order

If there is a conflict between fitting more content on the screen and improving usability, prioritize usability.

Priority should be:

Readability
Touch comfort
Appropriate input height
Appropriate button height
Comfortable spacing
Content density

Do NOT compress the UI simply to make more content visible without scrolling.

Some additional scrolling is acceptable if it results in a significantly more comfortable mobile experience.

VERY IMPORTANT — DO NOT MODIFY THE "Exchange" SECTION

The "Exchange" section must remain **100% unchanged**.

Do NOT modify anything inside the "Exchange" section.

Specifically, do not change:

* Input sizes
* Button sizes
* Typography
* Font sizes
* Colors
* Spacing
* Padding
* Border radius
* Layout
* Components
* Icons
* Alignment
* Visual hierarchy
* Existing interactions

The "Exchange" section must remain exactly as it currently is.

Apply all of the UI/UX improvements described above ONLY to the other sections of the application.

Final Goal

The final result should still look and feel like the same application, with the same visual identity, colors, dark theme, RTL structure, content, and functionality.

However, the overall experience should be significantly more comfortable and professional on mobile:

* Larger and more comfortable form fields
* Taller buttons
* Larger and more readable typography
* Gray internal placeholders inside simple form fields
* More internal padding
* Better spacing between elements
* Larger touch targets
* Better readability
* Consistent component sizing
* Consistent spacing and typography
